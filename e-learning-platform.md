# E-Learning Platform

> Proprietary project — case study only, no source code.

## Overview

An online learning platform that supports digital education, learning content, and learner-facing workflows.

**Problem:** Education providers need a web platform to deliver learning content and manage learners online.

**Solution:** A web-based system developed by the team to support these processes, which I contributed to as a full-stack developer.

## My Role

Full-Stack Developer in a development team. The system architecture and technical direction were defined by the team and technical leads; I implemented features across the frontend, backend, and database within that architecture.

## Responsibilities

- Frontend and backend feature development
- API integration
- Implementing authentication and authorization
- Database integration

## Key Features

Described at a high level to avoid disclosing confidential details:

- Learning content delivery
- User accounts with authentication and authorization
- Learner-facing workflows

## Technology Stack

| Layer | Technologies |
| --- | --- |
| Frontend | Next.js, React, TypeScript |
| Backend | NestJS, Node.js, REST API |
| Authentication | JWT |
| Database & Cache | PostgreSQL, Redis |
| Collaboration | Git, GitHub |

## Architecture

A web application with a separate frontend and backend communicating through REST APIs, backed by a relational database. Detailed architecture is not published for confidentiality reasons.

## Development

- Feature development in a shared codebase using Git branching and merging
- Implementing features according to business requirements and team conventions
- Debugging and fixing issues found during testing and in production

## Challenges & Solutions

- **Working within an existing, team-defined architecture:** kept new features consistent with the shared structure and conventions so they stay maintainable for the whole team.
- **Translating business requirements into features:** clarified requirements with the team before implementation to reduce rework.
